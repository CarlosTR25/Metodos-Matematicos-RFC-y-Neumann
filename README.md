# Métodos Matemáticos - RFC y Neumann 

Este repositorio contiene el código utilizado para generar las figuras del trabajo sobre expansiones multipolares, armónicos esféricos y funciones de Neumann.

## Contenido

El archivo principal es:

- `metodos-matematicos.py`

Este código genera tres figuras:

- `armonicos_bajos.png`: patrón angular de un armónico esférico con l = 2 y m = 0.
- `armonicos_altos.png`: patrón angular de un armónico esférico con l = 12 y m = 6.
- `neumann.png`: gráfica de las funciones de Neumann N0(x), N1(x) y N2(x) en el intervalo 0.01 <= x <= 20.
